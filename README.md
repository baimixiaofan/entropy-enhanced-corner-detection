# 熵增强角点检测 (Entropy-Enhanced Corner Detection)

基于邻域方向熵的上下文增强角点检测算法，与经典 Harris 角点检测的公平对比实验。

## 核心思想

角点与边缘在**梯度方向多样性**上有本质区别：

- **角点**：邻域内梯度方向分散（多条边在不同方向汇聚）
- **边缘**：邻域内梯度方向一致
- **平坦区**：梯度极弱，方向随机

用信息论的方式量化"方向分散度"——对邻域内梯度方向做直方图，计算 Shannon 熵：

$$H(p) = -\sum_{\theta} p(\theta) \log p(\theta)$$

方向熵大 → 像角点 → 增强；方向熵小 → 像边缘 → 抑制。

### 上下文增强公式

$$R_{new}(p) = R_0(p) \cdot (1 + \alpha \cdot H(p))$$

- $R_0$：初始角点响应（Harris 响应或梯度积 $|I_x \cdot I_y|$）
- $H$：幅值加权的邻域梯度方向熵（归一化到 $[0, 1]$），角度折叠到 $[0, \pi)$ 使直线边缘方向集中
- $\alpha$：增强系数（默认 3.0）

真角点方向熵高（增强 ~3.3×），噪声斑方向熵中等（~2.2×），从而**拉大角点与噪声的响应对比度**，同阈值下误检更少。

## 算法流程

1. Sobel 求梯度 $I_x, I_y$
2. 计算初始响应 $R_0$（`harris` 或 `grad` 模式）
3. 梯度方向折叠到 $[0, \pi)$，分 12 箱，幅值加权直方图（每箱一次 box filter 卷积，高效）
4. 计算方向熵 $H$，归一化到 $[0, 1]$
5. 上下文增强：$R = R_0 \cdot (1 + \alpha H)$
6. NMS（局部极大 + 平顶坍缩 + 最小距离抑制）+ 相对阈值
7. cornerSubPix 亚像素细化

## 对比实验结果

默认参数（threshold=0.05×max，α=3，与 Harris 完全相同的 NMS/细化流程，公平对比）：

| 测试图 | GT 角点数 | Harris F1 | 熵增强 F1 |
|---|---|---|---|
| 合成棋盘格 | 36 | 1.000 | 1.000 |
| 合成多边形（含圆形干扰） | 12 | 1.000 | 1.000 |
| 仿真照片（透视+噪声） | 49 | 1.000 | 1.000 |
| **弱对比 + 强噪声棋盘格** | 25 | 0.321 | **0.431** |

弱对比场景：两算法召回率相同（全中），**熵增强误检减少 38%**；阈值调到 0.1 时误检减少 3.4 倍（F1 0.847 vs 0.617）。

对比图在 `results/` 目录（含响应图、熵图、角点标记的可视化）。

## 快速开始

```bash
# 1. 生成合成测试图（棋盘格/多边形/仿真照片 + 真值）
python make_test_images.py

# 2. 跑对比：指标 + 6 面板可视化图
python compare.py

# 3. 用自己的真实图片对比（无真值，只统计角点数 + 定性图）
python compare.py test_images/你的图片.png

# 4. 阈值扫描（看两算法在不同阈值下的表现）
python threshold_sweep.py
```

依赖：Python 3, OpenCV (cv2), NumPy, matplotlib。

## 重要实现发现

1. **R0 用 Harris 响应而非梯度积**：`|Ix·Iy|` 无边缘拒绝能力，噪声和阶梯状栅格伪影处响应高且方向熵也高，反被增强放大。用 Harris 响应作 R0 时算法 = Harris × 熵加权，是干净的消融实验（`--r0 grad` 可切换体验差异）。
2. **噪声定位**：噪声会把响应峰值从真角点偏移 2~3px，必须做亚像素细化（两算法公平使用）。
3. **NMS 陷阱**：合成图响应平顶（多像素相等）会一个角点检出多个点，需平顶坍缩；噪声图同一角点周围有多个局部极大值簇，需最小距离抑制。
4. **测试图设计**：二值图对角线是阶梯状像素（每个台阶都是微型角点），需轻模糊；透视棋盘格要铺满画布，否则图案/背景边框整条线都是假角点。
